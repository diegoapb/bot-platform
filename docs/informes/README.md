# Informes de avance

Informes generados al cerrar cada sección de trabajo del proyecto.

## Nomenclatura

```
DDMMYY-HHMM-{titulo-descriptivo}.md
```

- **DDMMYY** — día, mes, año (2 dígitos cada uno). Ej: `050626` = 05/06/2026.
- **HHMM** — hora y minutos en formato 24h. Ej: `2044` = 20:44.
- **{titulo-descriptivo}** — slug en kebab-case del tema de la sección.

Generar el prefijo de fecha/hora con:

```bash
date "+%d%m%y-%H%M"
```
