# US-015 · Fundaciones del design system — tokens, fuentes y Tailwind

**Como** desarrollador del frontend, **quiero** los tokens del Open Solvex Design System (colores, tipografía, spacing, radios, sombras, animación) disponibles como CSS variables y en el theme de Tailwind, **para** construir y migrar la UI sin valores hardcodeados.

Es la base de toda la épica E09: sin tokens y fuentes cargadas, los componentes y las páginas no pueden alinearse al DS. No introduce cambios visibles por sí sola más allá de tipografía base.
